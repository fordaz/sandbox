# HOA CC&R Assistant

Manager web app for answering resident questions (email / WhatsApp) with replies grounded in the community's governing documents.

- [`UI_SPEC.md`](UI_SPEC.md): detailed UI specification (screens, components, flows, layout, data model) for implementing the full version.
- [`prototype/`](prototype/): source of the clickable design prototype (Design Component `.dc.html` files).
  - `Inbox.dc.html`: current design (Queue → Answer screens).
  - `Main.dc.html`: earlier "Ask the documents" exploration.
